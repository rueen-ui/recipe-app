# Recipe Catalog App

Каталог рецептов, где удобно подбирать блюда под свои цели: сразу видишь калории, белки, жиры, углеводы и клетчатку — и всё это с учётом реального размера порции, а не просто «на 100 г».

Стек: Next.js 16, TypeScript, Tailwind CSS.

## Как запустить

В терминале выполни:

```bash
npm install
npm run dev
Приложение откроется по адресу: http://localhost:3000

## Страница каталога

Тут все рецепты из базы. Для каждого сразу показываем, сколько в нём калорий и нутриентов именно под твой вес порции. Можно быстро отсортировать список или отобрать подходящие блюда.

## Фильтры

Легко найти то, что нужно прямо сейчас:

- по времени готовки: до 5, 15 или 30 минут;
- по калориям: до 150, 200 или 300 ккал;
- отметь «высокий белок» или «высокая клетчатка», чтобы видеть блюда, которые лучше подходят под эти задачи.

Все выбранные настройки сохраняются в адресной строке — если обновишь страницу или поделишься ссылкой, фильтры останутся.

## Избранное

Здесь собраны только твои любимые или подходящие рецепты. Приложение само посчитает общий итог: сколько всего калорий и нутриентов получится, если приготовить все эти блюда. Если ты поменяешь размер порции у какого‑то рецепта — итог сразу пересчитается.

## Страница отдельного рецепта

Полная карточка блюда: название, время, фото, описание. Тут тоже считаем калории и нутриенты под конкретный вес порции. Есть кнопка «В избранное» — одним нажатием можно сохранить рецепт или убрать его из списка.

## Где хранятся описания данных

Все описания данных хранятся в одном месте — в файле `lib/types.ts`. Так проще поддерживать порядок и не путаться.

## Разделение логики

Часть логики работает «на сервере» — она нужна, чтобы быстро отдавать данные и читать настройки из ссылки. Другая часть — «на стороне браузера»: она отвечает за кнопки, формы и сохранение твоих личных настроек (например, избранного).

## Фильтры и ссылки

Фильтры всегда отражаются в ссылке. Это нужно, чтобы настройки не пропадали при обновлении страницы и чтобы можно было легко поделиться нужным списком рецептов.

## Сохранение личных данных

Личные данные (избранное, веса порций) сохраняются прямо в браузере. Так они остаются с тобой даже после перезагрузки, но при этом не требуют сложной настройки сервера.
